feat: Phase 2-8 完全実装 (Tor 統合除く部分はコード上は実装、Tor は外部設定)

Phase 2: 添付ファイル
- 画像 (jpeg/png/webp/gif) + plain text のみ受信、PDF/Office/SVG/動画/音声は拒否
- MIME マジックバイト検証 (拡張子を信用しない)
- EXIF/XMP/ICC を decode → encode で除去、画像は再エンコード (PRNU 緩和)
- multipart/form-data ハンドリング + 個別/合計サイズ上限
- tar packing (meta.json + attachments/) + PKCS#7-style 64 KiB padding
- 検証済: 1363 → 1143 bytes (EXIF block 除去)

Phase 3: Tor 統合 (コード実装、外部 tor 必要)
- 自前 Tor Control 客 (stdlib のみ、外部依存なし)
- AUTHENTICATE (cookie / password / null auth 自動)
- ADD_ONION new:ED25519-V3 で .onion v3 を動的発行 (Flags=Detach)
- ADD_ONION で既存秘密鍵から復帰 → 同じ .onion アドレスを維持
- ClientAuthV3 で管理 onion を Client Auth 必須化
- config.tor.enabled で on/off、--no-tor フラグで run 時に強制 off

Phase 4: 受信者認証 + セッション + CSRF
- /admin/login (password + TOTP)
- セッション: in-memory only / 15 分 idle 失効 / HttpOnly / SameSite=Strict
- Secure 属性は .onion / TLS でのみ立てる (localhost テスト時は落とす)
- CSRF: HMAC(csrf_key, session_token) の double-submit token
- 匿名 form (/submit) の CSRF は PoW token に紐付け
- 全 POST が CSRF 検証

Phase 5: HKDF(code) 双方向通信
- 受信者→通報者の返信は HKDF-SHA256(code, case_id, "kakekomi/v1/reply-key") で対称鍵派生
- ChaCha20-Poly1305 (XChaCha20) で暗号化
- 通報者は /reply でコードを入力 → サーバが復号して表示
- 検証済: 受信者が code 入力 → reply 保存 → 通報者が /reply で復号読出し成功

Phase 6: PoW + size/timing 完全正規化 + pubkey pinning
- サーバ側 PoW: HMAC token 発行 + 5 分 lifetime + SHA-256 hash chain (~65k iter)
- ブラウザ JS 不要 (Tor Browser "Safest" モード対応)
- pubkey.lock: sha256(receiver.pub) を起動時に照合、不一致なら起動拒否
- timestamp は 1 時間粒度に丸めて保存・表示 (SPEC F-73)
- size bucket 表示 (<100KB / 100KB-1MB / 1-10MB / >10MB)
- レスポンスを 4 KiB 境界に padding (HTML コメントで)
- /submit に 2 秒固定 wait、/reply と /admin/login に 1.5/2 秒固定 wait

Phase 7: secrets.age + KDF master_key + Duress TOTP
- パスフレーズ → argon2id (256MiB / time=4 / threads=4) → master_key
- TOTP normal + duress / admin password hash / CSRF/Session MAC keys を ChaCha20-Poly1305 で暗号化保存
- run 起動時に stdin からパスフレーズ → in-memory 復号、起動完了後は master_key を zero 化
- Duress TOTP: 第二の TOTP で login すると全 case を shred + DB VACUUM、画面は通常の失敗と区別不能
- 検証済: 3 case あった blob/ が duress login で 0 case に、画面は "認証に失敗しました"
